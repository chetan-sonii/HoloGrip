HARDWARE LAYER

MPU6050 + ESP32

The MPU6050 provides accelerometer and gyroscope measurements. The ESP32 communicates with the sensor over I²C and acts as the embedded controller.

BACKEND LAYER

Flask + REST API

Flask keeps page routes separate from API routes and service logic. The API returns a structured sensor snapshot as JSON.

PRESENTATION LAYER

JavaScript + AJAX + 3D

Fetch requests retrieve current values, the DOM is updated in place, and the 3D scene can respond to orientation changes.
